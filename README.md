# PromptForge (Android Edition)

An Android toolkit to build, test, and evaluate AI prompts, rewritten in Kotlin and Jetpack Compose.

## Features

- **Composer**: Select prompt frameworks (CO-STAR, RISEN, etc.) and fill in slots to dynamically assemble your prompt.
- **Library**: Local persistence using Room DB to save your prompt iterations.
- **Playground**: Send prompts to Gemini and see the generated output directly in the app.
- **Eval Lab**: Run regression testing (A vs B testing) on prompts with automated scoring powered by Gemini API.
